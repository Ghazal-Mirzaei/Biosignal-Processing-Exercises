# Biosignal Processing Exercises

This repository contains weekly MATLAB and Python lab exercises completed as
part of a Biosignal Processing course in the Biomedical Engineering MSc program
at Hochschule Anhalt.

The exercises cover the fundamentals of signal processing with a focus on
biosignal and ECG analysis — from basic signal generation and visualization,
through hardware-based data acquisition, to real ECG signal processing and
feature extraction.

## Repository Structure

| Folder | Topic | Tools |
|--------|-------|-------|
| `Week01_Signal_Basics` | Signal generation, visualization, and introductory FFT | MATLAB |
| `Week02_Pulse_Rate_Measurement` | Pulse rate acquisition using Arduino and ADC | Arduino, MATLAB |
| `Week03_ECG_Rest_vs_Exercise` | ECG signal analysis: rest vs post-exercise comparison | Python |

## Topics Covered

- Continuous and discrete signal representation
- Periodic waveforms and signal superposition
- Frequency domain analysis (FFT)
- Analog-to-Digital Conversion (ADC) and serial data acquisition
- ECG signal filtering (Butterworth bandpass + notch)
- R-peak detection and RR interval analysis
- Heart rate variability (SDNN)
- PQRST waveform morphology

## Tools and Environment

- MATLAB (Signal Processing Toolbox)
- Python (NumPy, SciPy, Matplotlib, Pandas)
- Arduino IDE

## About

These exercises were completed as part of coursework in biomedical signal
processing at Hochschule Anhalt. The repository documents a progression from
basic signal generation to real biosignal acquisition and analysis, with a
focus on ECG and cardiovascular signal processing.
